# Trainer Guide

## Product Setup

- Complete trainer onboarding and public profile.
- Create courses/programs with lessons and materials.
- Publish paid products only after previewing the public storefront.
- Review pricing, descriptions, difficulty and category before launch.

## Sales And Access

- Use trainer sales dashboard for revenue, refunds and access signals.
- Use CRM to inspect customer history.
- Use reviews dashboard to reply to student feedback.
- Use schedule/booking tools for live or studio sessions.

## Operational Notes

- Payouts depend on payment settlement and risk holds.
- Refunded orders can revoke student access.
- Expired subscriptions should not grant protected content access.
