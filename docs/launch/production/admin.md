# Admin Guide

## Daily Checks

- Review `/admin/operations`.
- Review `/admin/payments`.
- Review `/admin/payouts`.
- Review `/admin/audit`.
- Review observability runtime status.

## Support Workflows

- Use global search to find users, orders, payments, payouts and content.
- Use support console for payment/access investigations.
- Use manual entitlement fix only with a clear reason.
- Resend notifications only after confirming the customer-facing event.

## Finance Workflows

- Review payout readiness and reconciliation reports.
- Export finance documents for accounting.
- Investigate chargebacks/disputes before resolving access holds.
